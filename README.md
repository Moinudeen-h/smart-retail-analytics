# Smart Retail Analytics Platform

## Overview

An end-to-end Data Engineering and Machine Learning platform that processes retail transaction data, stores it in PostgreSQL, automates workflows using Airflow, provides business intelligence dashboards, and generates predictive insights using Machine Learning.

## Architecture

Raw Data
↓
Python ETL Pipeline
↓
PostgreSQL Database
↓
Airflow Automation
↓
Power BI Dashboard
↓
Machine Learning Models


## Technologies

- Python
- PostgreSQL
- SQLAlchemy
- Apache Airflow
- Power BI
- Scikit-learn
- Docker
